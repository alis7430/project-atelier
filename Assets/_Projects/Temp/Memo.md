# Procedural map 만들기

## 고민점
1. 맵 프리펩을 하나만 놓는다
-  이번에 생성된 맵은 데이터로 저장됨
-  지도 열때마다 데이터 불러와서 표기
-  이게 맞는듯? 일단 이렇게 만들고 테스트하기!!!
-  생각해보니 풀링해도 되자나?

## 개발 방법
1. 맵 열기 기능과 데이터의 분리
2. NxM 크기의 절차적 맵 생성
3. 아래 요소들의 비주얼적 표기 기능
- 선택 가능한 노드
- 지나온 노드
- 지금까지의 경로
- 맵에 마우스 올렸을 때 정보
4. 맵 저장, 불러오기
5. 씬에서 한번 표기된 맵은 풀링하기
