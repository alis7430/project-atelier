# Procedural map 만들기

## 고민점
1. 맵 프리펩을 하나만 놓는다
-  이번에 생성된 맵은 데이터로 저장됨
-  지도 열때마다 데이터 불러와서 표기
-  이게 맞는듯? 일단 이렇게 만들고 테스트하기!!!
-  생각해보니 풀링해도 되자나?

## 개발 방법
1. 맵 열기 기능과 데이터의 분리
2. NxM 크기의 절차적 맵 생성
3. 아래 요소들의 비주얼적 표기 기능
- 선택 가능한 노드
- 지나온 노드
- 지금까지의 경로
- 맵에 마우스 올렸을 때 정보
4. 맵 저장, 불러오기
5. 씬에서 한번 표기된 맵은 풀링하기

### SystemRng
- 맵 생성
- 보상
- 전투
- 이벤트
- 상점
- 시드 재현이 필요한 로직

### UnityEngine.Random
- 파티클
- 애니메이션 변형
- 화면 연출
- 사운드 피치 변화
- 시드 재현이 중요하지 않은 요소
